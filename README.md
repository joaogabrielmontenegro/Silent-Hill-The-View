## Sobre o Projeto
Este projeto eh um prototipo de navegador panoramico interativo em 360. O sistema replica as mecanicas fundamentais do Google Street View, mas foi construido com uma atmosfera sombria de terror psicologico inspirada na franquia *Silent Hill*. 

## Documentacao do Projeto
O jogo foi desenvolvido na Unity (Versao 6000.3.20f1 LTS) e estruturado em multiplas cenas para simular a caminhada pela neblina.

**Controles:**
* **Mouse (Clique e arraste):** Rotaciona a camera (Pan) para olhar o ambiente em 360.
* **Scroll do Mouse:** Aplica Zoom In e Zoom Out na visao do jogador.
* **Teclado (WASD / Setas):** Navegacao secundaria de rotacao da camera.
* **Clique Esquerdo (Cenario):** Interage com os "Hotspots" (icones no chao) para andar ate a proxima area conectada.

**Mecanicas de Gamificacao e Diferenciais Implementados:**
* 
* Feedback sonoro autoral (trilha sonora tocada no piano).
* Minimapa dinamico via Canvas/UI.
